Windows will warn you (that's okay)

LightningLAN isn't signed with a paid certificate, so Windows is careful the first time you open it. You only do this once:

  1. If you see Windows protected your PC, click More info, then Run anyway.
  2. When the firewall asks, tick Private networks and click Allow access. Otherwise the others can't see your files.

No Run anyway button? Right-click the file, choose Properties, tick Unblock and open it again.

On Linux, make the file executable first (right-click it, then Properties › Permissions), then open it.
